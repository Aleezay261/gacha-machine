Gacha Notes
A little machine full of secrets
About the Project
Gacha Notes is a small interactive game I made for fun

The idea is to let someone send secret messages in a different way
instead of sending all the messages at once, they can hide them inside a
virtual gacha machine and share one link with someone

The other person can open the link, turn the dial, and reveal the
messages one by one

You can add up to 10 messages and 3 pictures to make the surprises more
personal
Features
- Add up to 10 secret messages
- Add up to 3 favourite pictures
- Preview the gacha machine before sharing
- Generate one link to share with someone
- Reveal messages one capsule at a time
- Use it for funny notes, wishes, reminders, or just a little surprise
How It Works
Creating a Gacha Machine
1. Write the messages you want to hide
2. Add up to 3 pictures if you want
3. Preview your machine
4. Copy the generated link
5. Share it with someone
Opening a Gacha Machine
1. Open the link you received
2. Tap the dial to turn the machine
3. Open the capsule and read the surprise
4. Keep turning to discover the other messages
Only HTML is used 
Running the Project
1. Download or clone the repository
2. Open the project folder in your code editor
3. Open the main HTML file in your browser
If the project uses a development server, run it according to the setup
for your project
Why I Made It
I wanted to make something simple and fun where people can send messages
in a more interesting way

It's a small project, but I liked the idea of turning normal messages
into little surprises that someone can open one by one
